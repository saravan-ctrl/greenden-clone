# 🌿 Greenton – Plant & Flower Website

Greenton is a responsive plant and flower website developed as a frontend web development project. The website provides a simple and attractive interface to explore different plants, flowers, and gardening products.

## 📌 About the Project

The main purpose of this project is to practice and demonstrate frontend development skills using HTML, CSS, and Tailwind CSS.

The website includes multiple pages with a clean navigation system and responsive layouts.

## 🌱 Website Pages

### 🏠 Home Page
- Greenton brand/logo
- Navigation bar
- Hero section
- Plant and flower introduction
- Promotional content
- Call-to-action buttons

### 🪴 Products Page
- Plant and flower products
- Product images
- Product names
- Product prices
- Product cards
- Hover effects
- Responsive product layout

### 📞 Contact Page
- Contact form
- Name field
- Email field
- Phone number field
- Message field
- Submit button
- Contact information
